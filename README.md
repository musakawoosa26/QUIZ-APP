# 🧠 QUIZ MASTER PRO (QUIZ APP)

> **Next-Generation AI-Powered Adaptive Quiz Platform**  
> Modern Glassmorphic & Neo-Sleek UI powered by **CustomTkinter**, Google Gemini AI, and Procedural Question Generation.

---

## ✨ Features

- 🎨 **Modern Neo-Sleek UI**: Built with CustomTkinter featuring glassmorphic accents, dark/light themes, and smooth micro-animations.
- ⚡ **Adaptive Difficulty Engine**: Dynamically scales challenge levels based on player performance and accuracy.
- 🤖 **Gemini AI Integration**: Generates custom, contextual questions on any topic in real-time.
- 📊 **Analytics & Leaderboard**: SQLite-backed local tracking for scores, streaks, category breakdowns, and performance history.
- ⏱️ **Timed Challenges & Modes**: Practice mode, timed sprints, and custom category challenges.
- 🛡️ **Cross-Platform**: Runs natively on macOS, Windows, and Linux.

---

## 🚀 Quick Start

### 1. Prerequisites
- Python 3.10+ (tested with Python 3.14)
- `pip` package manager

### 2. Installation

Clone the repository and install the dependencies:

```bash
git clone https://github.com/<your-username>/QUIZ-APP.git
cd QUIZ-APP
pip install -r requirements.txt
```

### 3. Running the App

Launch the application:

```bash
python3 quiz_application.py
```

*(Optional)* To enable AI-generated questions, provide your Google Gemini API key inside the app settings.
